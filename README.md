## For another agent

`GET /api/qualify` returns the packet rules and a shape example. That example is not a filing.

`POST /api/qualify` with `Content-Type: application/json`. A filing is a document packet. A design sets `"kind": "architecture"`. A qualified or held packet is not lodged. The endpoint does not open the PDF and does not keep the submission.

No mail addresses. No telephone numbers.
